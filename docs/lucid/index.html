Lucid

A clear, accessible theme for teaching and technical writing

Principles, installation, options, customisation, and base typography.

Lucid is a Quarto format for material that people study rather than skim: textbooks, course sites, lab manuals, and technical reports. It favours legible type, a palette that stays distinguishable for colour-blind readers, restrained geometry, and interactions that work from a keyboard.

Principles

Clarity first
Prose sits at a measure of 76 characters. Headings use Jost, body text uses Libre Franklin, and numbers in tables share one width so columns line up.
Colour that works for every reader
Accents come from the viridis scale, which stays perceptually even and distinguishable under common colour-vision deficiencies. Neutrals are charcoal and paper.
Restrained geometry
Corners are nearly square. A component gets one hairline frame and one coloured edge, never a heavy shadow.
Accessible by default
Table headers carry scope, wide tables become focusable scroll regions, collapsible callouts respond to Enter and Space, and diagrams receive an SVG title and description.
Faithful on paper
Print styles switch to black on white, hide navigation, and keep tables, pseudocode, and diagrams legible.

Install and use

quarto add brenobeirigo/quarto-themes
format:
  lucid-html: default

Any ordinary HTML option still works under lucid-html. For a book, also set reader-mode: true under book: to enable the wide reading layout.

Options

Each enhancement can be switched off under lucid: in document or project metadata.

lucid:
  copy-refs: false
  page-references: true

Customise

Colours and fonts

Every token in lucid-light.scss and lucid-dark.scss is a !default Sass variable. Put your values in a brand file and list it after the palette. Listing a theme replaces the one the format supplies, so name the Lucid layers too.

/*-- scss:defaults --*/
$lucid-accent: #2a9d8f;
$lucid-accent-strong: #1d6f65;
$lucid-font-heading: "Source Serif 4", Georgia, serif;
format:
  lucid-html:
    theme:
      light:
        - cosmo
        - _extensions/brenobeirigo/lucid/scss/lucid.scss
        - _extensions/brenobeirigo/lucid/scss/lucid-light.scss
        - brand.scss
      dark:
        - darkly
        - _extensions/brenobeirigo/lucid/scss/lucid.scss
        - _extensions/brenobeirigo/lucid/scss/lucid-dark.scss
        - brand.scss

One component

Components read CSS custom properties, so a small stylesheet can adjust them without recompiling the theme.

.landing-page {
  --lucid-accent-light: #ffd166;
}

Code

def running_total(values):
    """Return the cumulative sum after each value."""
    total = 0
    totals = []
    for value in values:
        total += value
        totals.append(total)
    return totals
