Reasoning with data

Turn an unclear question into an analysis that another person can inspect, test, and improve.

Each module pairs a short reading with worked examples, a traced algorithm, and a practice set with solutions.

What you will be able to do

01

Frame the problem

State the decision, the inputs, the constraints, and what would count as a correct answer before touching data.

02

Trace before you run

Follow an algorithm step by step on paper so that surprises in code become questions you can answer.

Every result in this course comes with the evidence that supports it and the assumptions that limit it.
