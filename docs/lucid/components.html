Components

Tables, pseudocode, diagrams, exercises, and worksheets

Every Lucid component with the markup that produces it.

Data tables

Add .data-table to a captioned table for a dark header, banded rows, and a frame. Add .row-headers when the first column names each row.

: Planned tests for a 10-seat minibus {#tbl-minibus-tests .data-table .row-headers}

Trace tables

A .trace-table keeps its first column visible while the rest scrolls, so each step stays next to its state.

Great Tables

Output from the Great Tables package is framed automatically. Grids with a stub column give it room and keep it in view on small screens.

Pseudocode

A fenced block with the .pseudocode class becomes a numbered terminal. Readers can link to a line.

booked ← 0
for each request in requests
    if booked + request ≤ capacity then
        booked ← booked + request
        record "book"
    else
        record "reject"
    end if
end for
return booked
```{.pseudocode}
booked ← 0
...
```

Flowcharts

Mermaid diagrams keep their natural size and scroll when wider than the column. Lucid adds an SVG title and description taken from the caption.

Exercises and solutions

A label inside a heading gets a copy-reference button. A callout titled Solution [-@exr-id] is retitled with the exercise identifier.
